# Brand asset provenance

- `peyajflow-logo-transparent-raster.png` is the supplied 311 × 59 RGBA logo. `apps/web/public/peyajflow-logo.png` is a byte-for-byte copy.
- `apps/web/public/peyajflow-icon.png` is a transparent 64 × 64 favicon. The first 54 columns of the supplied lockup were copied at offset (5, 2), excluding the wordmark. The symbol pixels retain the original geometry and colors.
- The asset is an interim screenshot-derived raster, as described in the master handoff. The owner vector artwork remains pending.
- The portfolio landing photograph was generated with the built-in image generation tool and exported as `apps/web/public/onion-storage.webp`. The same image and a detail crop are used for the fictional inspection fixture. The prompt requested documentary-style red onions and a woven bamboo basket in a naturally lit Bangladeshi storage shed, with jute sacks and wood crates, and no people, text, logos, or watermarks.
